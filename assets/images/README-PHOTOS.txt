Fichiers prévus pour les vraies photos de chantier :

- hero-chantier.webp          : photo principale du haut de page (facultatif)
- chantier-placo.webp         : réalisation placo / cloisons / isolation
- chantier-peinture.webp      : réalisation peinture intérieure
- chantier-agencement.webp    : réalisation agencement / parquet

Conseil : WebP, largeur 1200 à 1600 px, compression web (~150 à 400 Ko selon la photo).
Les 3 images de galerie sont détectées automatiquement par index.html dès qu'elles existent.
